1. Purpose and scope

Conversation Timeline Helper is an unofficial navigation tool for the ChatGPT and Gemini websites. It provides a fixed-height timeline, message previews, search, bookmarks, and navigation to an original message after user interaction. It is not affiliated with, sponsored by, or endorsed by Microsoft, OpenAI, ChatGPT, Google, Gemini, or Reborn14.

Content scripts run only in top-level pages on chatgpt.com, chat.openai.com, and gemini.google.com. The extension does not scan other conversations in the account, restore deleted messages or hidden branches, or automatically load the entire conversation history while idle.

2. Information processed locally and why

Loaded conversation content: the extension reads prompts, replies, message roles, order, available message identifiers, and positioning information from the current page's rendered DOM to build its timeline, search, and previews. Conversations may contain personal or sensitive information. The extension does not extract that information into a separate profile or use it for profiling.

Current conversation path: the current page's conversation path and necessary temporary-chat flags are read locally to detect conversation changes, separate bookmarks, and verify navigation. The extension does not request the browser history permission, read global browsing history, or record visits to other websites.

Interaction information: scroll direction, marker clicks, keyboard navigation, search terms, and bookmark actions are used only for immediate navigation, search, cancellation, and saving the user's choices. The extension does not build behavioral logs or perform usage analytics, advertising analytics, or telemetry.

Settings and bookmarks: chrome.storage.local saves enabled state, theme, interface language, message scope, placement, keyboard preferences, custom message selectors, conversation/message identifier fingerprints, and bookmark timestamps. Automatic language mode reads the browser's language preferences. All interface translations are bundled; no conversation or interface content is sent to a translation service. Gemini and ChatGPT use separate bookmark scope prefixes. Pages without a stable conversation ID use temporary in-memory bookmarks. The version 1 bookmark backup format is retained. Conversation bodies, full conversation URLs, and search terms are not saved in extension persistent storage. Fingerprints are small noncryptographic matching identifiers, not encryption or a guarantee of anonymity or nonreversibility.

Image or attachment preview position protection: a message anchor and viewport offset from before a preview was opened are temporarily kept in the current tab's memory to preserve the reading position after it closes. They are cleared when the short correction period ends, the conversation changes, or the extension stops. They are not written to persistent extension storage or sent to another page or service.

Return to reading: up to 20 positions from before user-triggered navigation jumps are kept only in the current tab's memory. They are cleared on a conversation change, refresh, disabling the extension, or rebuilding the index, and are not exported as browsing history.

Sections and nearby message choices: headings, heading levels, and order are extracted from loaded replies for local navigation. Nearby-message scope and expanded sections also remain in the current tab's memory. The extension does not generate or upload AI summaries.

3. Retention and deletion

Message text, the index, necessary navigation checkpoints, and search state are used only in the current tab's memory. Refreshing or closing the tab, changing conversations, disabling the timeline, or rebuilding the index resets the relevant page index. This is not a promise of secure erasure of browser memory. The original website's stored conversations are controlled by that website, not this extension.

Messages previously observed in the current page may remain indexed after the website temporarily unmounts them. If a message or the total text budget is too large, only an excerpt or message marker may be retained. This extension is not a conversation backup service.

Settings and persistent bookmark markers remain in the current browser profile until the user resets or clears them, deletes extension storage, or uninstalls the extension. Temporary-chat bookmarks are not persisted. Disabling the timeline does not delete persistent bookmarks. The extension does not use chrome.storage.sync to synchronize this data.

Use Advanced & Data to clear local bookmarks, Restore defaults to reset settings, or the browser's extension manager to uninstall. Clearing data or uninstalling does not delete JSON or Markdown files already exported by the user, or delete the original ChatGPT or Gemini conversations. Exported files must be deleted separately by the user.

4. Network activity, page communication, and sharing

The extension itself does not transmit conversations, bookmarks, search terms, or usage data to its developer, advertisers, analytics services, or third-party servers. It does not read passwords, cookies, login tokens, or payment information, intercept website requests, or construct conversation API requests.

After the user selects a previously loaded message, the extension may scroll the page, activate an identified native history-pagination control, or call an existing ChatGPT virtual-list positioning method. The website may then make its own native loading requests to its service. This is distinct from the extension uploading data to its developer. Esc, manual scrolling, or Cancel stops subsequent extension navigation actions; website requests already triggered may not be reversible.

The ChatGPT isolated script and MAIN-world navigation helper exchange short-lived request identifiers, conversation paths, observed message keys, positioning parameters, and execution status within the current page only. They do not exchange conversation bodies, extension persistent storage, or authentication credentials. This page communication is not confidential from the website itself, and actual DOM verification is still required. Gemini uses DOM observation and scrolling after an explicit user selection, without injecting or calling the ChatGPT MAIN-world helper.

The extension does not sell or rent this data, provide it for advertising, data brokering, credit decisions, lending, or unrelated purposes, or use conversations to train models.

5. Import, export, and diagnostics

Markdown message export happens only after the user selects Export in the outline. It creates a local download containing the loaded messages in the currently displayed, searched, bookmarked, or nearby-message scope, including their available formatting. It does not load unseen history or download original image files. Unmounted messages may use observed plain-text cache, with a note in the file. The output can contain personal information and original links. The user controls saving, sharing, and deleting it. Exported text is not written to chrome.storage.local or uploaded to a developer service.

Bookmark backup is exported only after user action. The file contains a format version, export time, identifier fingerprints, and bookmark timestamps, without conversation bodies. A file selected for import is validated locally and only allowed bookmark fields are merged.

A diagnostic export contains extension version, detection counts, adapter name, index state, and technical navigation stage, steps, duration, and failure reasons. It excludes conversation bodies, raw message IDs, search terms, conversation URLs, and custom selectors. There is no automatic diagnostic upload. Review diagnostic files and screenshots before voluntarily sharing them; do not send passwords, tokens, or private conversations.

6. Permissions and code

The only explicit browser API permission is storage, used for local preferences and bookmarks. Content-script site access is limited to the three domains above. The extension does not request all-websites, cookies, debugger, webRequest, or history access. It has no background service or remotely executable code. Runtime scripts and styles are bundled in the installation package.

The popup uses basic chrome.tabs query and message communication to obtain the active tab ID, without reading sensitive URLs or titles of other tabs or requesting the tabs permission. Microsoft or Google separately handles its own store distribution, updates, and platform statistics under its own policies. Those activities are not conversation uploads by this extension.

Visiting a hosted page still sends an ordinary HTTP request to the hosting provider. That provider may process an IP address, request path, browser identifier, or access logs under its own policies, separately from the extension's local processing.

Processing by the extension is limited to the navigation, user-requested export, and voluntary support purposes described here. Conversation data is not used for personalized advertising, sale, unrelated purposes, or human review without consent. Store platforms assess submissions under their developer terms and review processes; this policy is not a statement of Microsoft or Google certification.
