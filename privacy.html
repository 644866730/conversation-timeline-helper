1. 功能与适用范围

本扩展是用于 ChatGPT 网页版的非官方对话导航工具，提供固定高度时间轴、悬停预览、本页消息搜索、收藏及用户点击后的原消息定位。它与 OpenAI、ChatGPT 及 Reborn14 不存在官方隶属、赞助或认可关系。

扩展内容脚本只在 chatgpt.com 和 chat.openai.com 的顶层页面运行，不在其他网站运行，不扫描账号中的其他会话、不恢复已删除消息或隐藏分支，不在空闲时补全全部历史。

2. 在本地处理的信息及用途

已加载对话内容：读取当前页面已呈现的提问、回复文本、消息角色、顺序、可用消息标识及定位信息，用于时间轴、搜索和预览。内容可能包含用户写入的个人或敏感信息；扩展不会将其另行提取为个人资料或用于画像。

当前会话路径：在页面内读取当前会话路径及必要的临时会话标志，用于识别切换会话、隔离收藏及校验导航。扩展不请求浏览器 history 权限，不读取全局浏览历史，不记录其他网站访问。

必要的交互信息：页面滚动方向、点击节点、键盘导航、搜索词及收藏操作仅用于即时导航、检索、取消跳转和保存用户选择。不建立行为日志，不做使用统计、广告分析或遥测。

设置与收藏：chrome.storage.local 保存开关、主题、显示范围、位置、快捷键、自定义消息选择器等设置，以及会话/消息标识的指纹和收藏时间。它不保存聊天正文、完整会话 URL 或搜索词。指纹是用于匹配的小型非密码学标识，不是加密，也不保证匿名或不可反推。

3. 数据保留与删除

消息文本、索引、必要的定位检查点与当前搜索状态只在当前标签页内存中使用。刷新或关闭标签页、切换会话、关闭时间轴或重建本页索引会重置相关页面索引；这不是对浏览器内存作安全擦除的承诺。网页自身保存的聊天不受本扩展控制。

网页暂时卸载旧消息后，本页已观察到的节点仍可保留。超长正文或总内存预算超限时，可能只保留摘要或节点；本扩展不是聊天备份工具。

设置与持久收藏在当前浏览器配置中保留，直至用户重置/清空、删除扩展本地数据或卸载扩展。临时会话收藏不持久保存。关闭时间轴不会删除持久收藏。扩展不使用 chrome.storage.sync 自动同步这些数据。

可在“高级与数据 → 本地收藏与备份”清空收藏，在“恢复默认设置”重置设置，或通过浏览器卸载扩展。清空和卸载不删除用户已导出的 JSON 文件，需要用户自行删除这些文件。它们不会删除 ChatGPT 原聊天。

4. 网络、页面内通信与共享

扩展自身不向开发者、广告商、分析服务或第三方服务器发送聊天、收藏、搜索或使用数据，不读取密码、Cookie、登录令牌或支付信息，不拦截网页请求，也不自行构造会话接口请求。

用户点击已加载过的节点时，扩展可能滚动页面、点击原生历史分页按钮，或调用页面已有虚拟列表定位方法。ChatGPT 网页因此可能按其自身逻辑向其服务发起原生加载请求。这不是扩展向开发者上传数据。用户可按 Esc、手动滚动或点击“取消”停止扩展后续导航动作；已触发的网页请求不一定能撤回。

隔离脚本和 MAIN 世界定位助手只在当前页面内交换短期导航请求标识、会话路径、已观察的消息 key、定位参数和执行状态，不交换聊天正文、扩展持久存储或认证凭据。页面内通信不对网页自身保密；完成定位仍需校验实际 DOM。

本扩展不出售、出租或提供数据用于广告、数据经纪、信用评级、放贷或与导航无关的用途，也不使用聊天训练模型。

5. 导入、导出与诊断

收藏备份仅在用户操作时导出到用户选择的本地文件，包含格式版本、导出时间、标识指纹与收藏时间，不含聊天正文。用户主动导入的文件只在本地校验并合并允许的收藏字段。

诊断导出包含扩展版本、识别计数、适配器名称、索引状态、导航阶段/步骤/耗时/失败原因等技术信息，不包含聊天正文、原始消息 ID、搜索词、会话 URL 或自定义选择器。扩展没有自动上传诊断的功能。请在主动分享诊断或截图前自行检查内容；不要发送密码、令牌或私人聊天。

6. 权限与代码

唯一的显式 API 权限是 storage，用于保存本地设置与收藏。内容脚本的访问范围仅限上述两个站点。扩展不请求所有网站、Cookie、debugger、webRequest 或 history 权限，没有后台服务和远程可执行代码，运行脚本与样式随安装包提供。

扩展弹窗使用 chrome.tabs 的基本查询和消息通信取得活动标签 ID，不读取其他标签的敏感 URL 或标题，也不申请 tabs 权限。Chrome 自身的商店分发、更新和统计由 Google 按其政策处理，不属于扩展向开发者上传聊天。

7. 网站访问与自愿支持联系

公开介绍/隐私/支持页面不包含本项目添加的追踪脚本、第三方字体、分析 SDK 或支持表单。访问页面仍需向网站托管服务发送普通 HTTP 请求；托管服务可能按其政策处理 IP 地址、请求路径、浏览器标识和访问日志。这与扩展运行时的本地数据处理不同。

用户主动发送支持邮件时，提供的信息将用于处理该支持请求；请只提供排障所必需的信息。发布者不通过扩展自动获取聊天。对用户明确同意分享的具体排障材料，仅作支持用途，并按用户要求及适用保留义务处理删除。

8. 限定用途与变更

对话时间轴助手对用户数据的使用遵守 Chrome 网上应用店用户数据政策，包括 Limited Use（限定用途）要求。数据只用于本政策及商店页面披露的单一用途，不作个性化广告、出售或无关用途，不允许未经同意的人工阅读。任何必要的其他处理必须符合适用法律及该政策的例外范围。

如未来功能、权限或数据处理发生变化，发布者应同步更新本政策和商店披露，并在需要时取得用户同意。当前政策不承诺所有网页灰度界面均可识别或导航成功。
