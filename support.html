使用与支持

先从常见排查开始。扩展只在当前对话中处理已加载内容。

在 Edge 或 Chrome 安装源码

在 Edge 打开 edge://extensions/，或在 Chrome 打开 chrome://extensions/，开启开发者模式，加载仓库中直接包含 manifest.json 的 extension 目录。不要将仓库根目录作为扩展目录。更新前先导出需要的收藏，只启用一个版本。

目录入口遮挡顶部按钮

v1.8.1 已将目录入口与轨道整体下移 64px。请重新加载扩展，再刷新 ChatGPT 和 Gemini 页面；入口现在位于网页顶部操作区下方。

安装后没有出现时间轴

  1. 确认扩展已启用，并允许在对应网站运行。
  2. 打开 chatgpt.com、chat.openai.com 或 gemini.google.com 中的一段对话。
  3. 安装或更新后刷新该网页。
  4. 点击扩展图标查看是否连接到页面，再尝试「重新识别」。

旧消息没有出现，或点击后暂未定位

本扩展不在后台自动补全全部历史。先用网页自己的方式加载需要的内容，扩展会记录本页实际观察过的节点。点击旧节点后可按需尝试恢复原消息；若网站结构或虚拟列表无法恢复，会提示重试。手动滚动、Esc 和取消按钮可以停止后续定位。

如何搜索、收藏和查看章节

打开页面侧边的「目录」并输入关键词，或点击星标收藏。回复有实际标题时，可展开「查看章节」。点击「返回阅读处」可回到主动跳转前的位置。章节原文和聊天正文不会被界面语言设置翻译。

如何切换语言和主题

在扩展弹窗或独立设置页的「常用设置」选择界面语言、深浅主题或左右位置。支持简繁中文、英语、日语、韩语、西班牙语、法语、德语，也可跟随浏览器。切换语言会保留搜索、收藏和当前阅读状态。

如何导出或删除本地数据

目录中的「导出」保存当前筛选范围内已加载消息的 Markdown 文件。「高级与数据」提供收藏备份、清空收藏和恢复默认设置。导出文件由你自行保管和删除；清空扩展数据不会删除网站上的原聊天。

如何提供诊断

在「高级与数据」主动导出诊断后，先自行检查文件。诊断设计为不含聊天正文、原始消息 ID、会话 URL、搜索词和自定义选择器。扩展不会自动上传。截图可能显示聊天内容，请先遮盖或改用不含私密内容的测试对话。

快捷键

Alt+Shift+T
打开或收起目录
Alt+Shift+F
打开消息搜索
Alt+Shift+↑ / ↓
上一条或下一条消息
Esc
取消定位或收起目录
