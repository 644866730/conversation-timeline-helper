对话时间轴助手
CONVERSATION TIMELINE HELPER · v1.8.0
产品介绍 · 隐私政策 · 使用支持 · English

长对话，有序可循。

为 ChatGPT 与 Gemini 网页提供对话时间轴、消息目录和本地收藏。固定高度、无滑条，让长对话更好找。

顶部是本页加载过的最旧消息，底部是最新消息。随着你加载更多内容，较旧节点逐渐压密。点击节点定位原消息，在目录中搜索已加载消息、展开回复章节，或查看收藏。

不后台补全历史 · 正文在当前标签页内存处理 · 不向开发者上传聊天

v1.8.0 可以做什么

  • 提问与回复时间轴、悬停预览、消息搜索和关键词上下文高亮。
  • 本地收藏及备份、回复章节导航、密集节点附近消息选择。
  • 主动跳转后返回刚才的阅读处，导出当前筛选列表的 Markdown。
  • 简体中文、繁体中文、英语、日语、韩语、西班牙语、法语、德语，或跟随浏览器。
  • 深浅主题、左右位置、键盘操作及图片/附件预览阅读位置保护。

适用于 chatgpt.com、chat.openai.com 和 gemini.google.com。界面语言在设置中切换，自动保存并同步到已打开的时间轴；聊天正文和章节原文保持不变。

本扩展不提供额外 AI 模型，不需要扩展 API Key。使用 ChatGPT 与 Gemini 本身的条件由对应服务决定。网页改版和账号灰度布局可能影响消息识别或定位；扩展不扫描账号中的其他会话。

在 Edge 与 Chrome 使用

开源工程使用 Manifest V3。源码安装可在 edge://extensions/ 或 chrome://extensions/ 开启开发者模式，加载仓库中的 extension 文件夹，再刷新 ChatGPT 或 Gemini。公开源码和网站不代表扩展已经通过任何商店审核。

持续适配与更新：跟进 ChatGPT 与 Gemini 的页面结构及阅读交互，维护兼容性。查看更新记录；兼容问题可在 GitHub Issues 反馈。
