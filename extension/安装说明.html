对话时间轴助手 · 1.8.1
ChatGPT 与 Gemini · 让长对话，更好找。

安装与更新

无需编译，解压后即可加载。

首次安装

  1. 把安装 ZIP 解压到固定目录。
  2. 在 Edge 打开 edge://extensions/，或在 Chrome 打开 chrome://extensions/，启用「开发者模式」。
  3. 点击「加载已解压的扩展程序」，选择直接包含 manifest.json 的目录。
  4. 刷新 ChatGPT 或 Gemini，点击页面边缘的「目录」开始查找。

更新已有版本

先在旧版「高级与数据 → 本地收藏与备份」导出收藏。使用原来的扩展目录时，在扩展管理页点击重新加载，再刷新 ChatGPT 和 Gemini 已打开的标签页。1.7.0 新增 gemini.google.com 站点访问，浏览器可能要求确认。若新目录被浏览器识别成另一个扩展，请停用旧版并导入备份；收藏格式继续兼容 v1，既有 ChatGPT 收藏键保持兼容。

1.8.1 位置修复

目录入口与时间轴轨道整体下移 64px，避开网页顶部的下载、全屏等原生按钮。更新扩展并刷新网站后生效；入口不会遮住最旧消息节点，轨道底部仍保留 40px。

在 Gemini 使用

打开 https://gemini.google.com/app 并选择对话。会话地址识别支持普通 /app/<会话ID>、Gem /gem/<GemID>/<会话ID>、/share/<分享ID> 和相应账号前缀。Gemini 与 ChatGPT 收藏隔离；没有稳定会话 ID 的页面只保留临时收藏。Gemini 读取当前页面 DOM，并在主动选择旧节点后尝试通过原页面滚动恢复，不运行 React MAIN 定位助手。

语言切换

在「常用设置 → 界面语言」选择八种语言之一，或跟随浏览器。切换后自动保存，并实时更新已打开的 ChatGPT 与 Gemini 时间轴。聊天正文和章节原文保持不变。

这一版可以做什么

  • 用固定高度的时间轴定位提问和回复，密集圆点可展开附近消息逐组选择。
  • 搜索已加载消息，在结果中看到命中词及上下文。
  • 回复下「查看章节」可直接定位到答案中的标题。
  • 通过方向键选择结果，Enter 定位，Esc 收起。
  • 查阅旧消息后，点击「返回阅读处」恢复原来的位置。
  • 在本地收藏消息，导入和导出收藏标记。
  • 目录底部「导出」将当前显示、搜索、收藏或附近列表保存为 Markdown。

索引仅覆盖本页实际加载过的内容。扩展不会在空闲时补全全部历史，返回位置只保存在当前标签页内存。

遇到问题

安装或更新后先刷新当前 ChatGPT 或 Gemini 页面。如果目录仍未识别到内容，在设置的「高级与数据 → 适配与诊断」重新识别并查看诊断。已查看已登录 Gemini 的页面结构，但这不代表完整真实功能回归已完成。网站灰度界面可能不同，请以当前版本的实际验收说明为准。
