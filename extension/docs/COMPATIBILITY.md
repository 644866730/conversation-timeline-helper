# 兼容性与边界 · v1.8.0

1.8.0 新增八种界面语言与跟随浏览器选项，站点匹配和权限保持不变。语言切换与本地验证范围见 [语言支持说明](LANGUAGE_SUPPORT.md)。

## 平台与访问范围

Manifest V3，最低清单要求 Chrome 120。隔离内容脚本只在 `chatgpt.com`、`chat.openai.com` 与 `gemini.google.com` 的顶层页面运行，显式 API 权限仍只有 `storage`。1.7.0 新增 Gemini 站点访问，更新后应重新加载扩展并刷新两平台的标签页；浏览器可能要求确认新增站点访问。

React MAIN 定位助手仅匹配两个 ChatGPT 域名，不在 Gemini 注入或运行。Gemini 使用 DOM 观察和用户主动选择后的原页面滚动恢复；不会读取 Angular/React 私有状态、账号接口或认证信息。

## DOM 识别与会话地址

ChatGPT 保留新旧显式角色结构，包括 `data-message-author-role`、`data-turn`、`data-turn-key`、`data-content-search-unit-key`、用户气泡及稳定消息 ID。可选虚拟列表定位也会记录实际 turn key 和可用的 DOM 位置提示。

Gemini 由独立的 DOM 适配识别用户提问与模型回复，消息正文和标题只从当前已加载内容中提取，排除输入草稿、操作工具栏、隐藏分支及其他无关区域。DOM 标记是实际页面观察结果，不是 Google 或 OpenAI 提供的稳定扩展协议；网站更新与灰度差异可能使识别失效。

Gemini 会话地址识别支持：

- 普通会话：`/app/<会话ID>`。
- Gem 会话：`/gem/<GemID>/<会话ID>`。
- 分享页：`/share/<分享ID>`。
- 以上地址的 `/u/<账号序号>/` 前缀。

地址识别用于会话切换与收藏作用域，不保证这些页面上的所有内容布局均可识别。`/app`、Gem 首页等没有稳定会话 ID 的页面，收藏只在当前标签页内存有效。

## 收藏、顺序与显示

Gemini 和 ChatGPT 使用不同的平台作用域前缀，即使会话标识相同，也不会匹配到对方平台的收藏。既有 ChatGPT 收藏键保持兼容，收藏导入导出继续使用 v1 格式。显示范围、主题与快捷键设置由同一扩展共用。

索引使用重叠稳定标识作为前后顺序锚点，保留本页观察过但暂未挂载的消息。完全不重叠且没有全局位置提示时，按实际滚动方向推断；无稳定 ID、重复正文或局部序号复用时不保证顺序绝对无误。诊断中的 `inferredOrderBatches` 可用于排查。

轨道首尾按显示范围计算：只看提问时为最旧/最新的已加载提问；显示双方消息时覆盖已观察的提问与回复。搜索筛选不改变轨道，密集节点选择也不增加轨道高度。页面中没有可用发送时间时，不会编造时间标签。

## 点击后的定位

1. 重新扫描。已经挂载的消息直接对齐，避免使用被网站重用的过时 DOM 引用。
2. ChatGPT 可尝试原生虚拟列表。MAIN 助手仅在本次请求中有限检查描述符，优先使用实际 key 调用 `scrollToIndex` / `scrollToItem`。记录索引只在当前挂载锚点校准一致时作为辅助，不凭消息序号猜真实列表索引。
3. Gemini 跳过 React MAIN 定位。未挂载消息由记录的位置和当前实际消息顺序决定主动滚动方向，等待网站原生加载；ChatGPT 原生助手不可用时也采用此回退。
4. 找到目标后复核真实 DOM、身份与可见范围，再做有限布局校准。章节定位还会重新确认标题；标题消失或变化时提示并退回所在回复。

单次定位有时间、步数和无进展上限。不能恢复目标时给出重试或关闭提示，不使用缓存正文窗口冒充成功。首次点击旧节点可能需要等待多次原生加载，不保证瞬间跳到很早的消息。

不会为了导航而重载整个网站、构造猜测参数 URL、请求账号 API、打开其他会话或修改网页框架状态。空闲时不自动补全历史。

## 取消、预览与生命周期

滚轮、触屏或网页点击、Esc、取消按钮、选择另一个目标、切换会话、页面隐藏、关闭扩展和重建索引会停止旧定位的后续动作。对应网站已经发出的原生加载请求不一定能撤回。

图片与附件预览打开时，时间轴暂停交互并暂存实际阅读锚点，关闭后在有界窗口内尝试恢复。新的手动操作会停止剩余校正。普通页面菜单不应被当成媒体预览；未知的预览组件仍可能需要后续适配。

不恢复隐藏分支、已删除消息或跨刷新正文缓存。同一 URL 下改变分支后，旧索引可能仍含之前观察过的节点；若目标不可达，可重建本页索引，不会删除原聊天。

## 导出边界

Markdown 仅导出当前显示、搜索、收藏或附近列表中的已加载消息。已挂载正文尽量保留常见结构，未挂载内容使用已观察的纯文本缓存并注明；不下载图片/附件原文件，不后台补齐未加载内容。复杂交互卡片与未知组件可能有格式损失。

## 验证边界

本版本已查看已登录 Gemini 页面的 DOM 结构。这与本地模拟测试、原生扩展安装验收、完整的真实会话回归是不同范围，不应互相替代。

现有 Chromium 测试使用本地聊天 DOM 和 Chrome 存储/消息 API mock；部分 ChatGPT 定位测试使用真正的 MAIN/ISOLATED 世界隔离。实际功能验证、测试记录与未验证范围应按当前版本交付说明理解，不由本文承诺所有账号、灰度界面、语言与预览组件均已通过。
