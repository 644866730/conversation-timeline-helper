# v1.6.0 · 长对话实用工具

更新日期：2026-11-16。沿用 v1.5.0 的 Soft Utility 视觉风格。

## 功能与用法

### 回复章节目录

目录里的助手回复如果包含实际的 h1–h6 标题，会显示「查看章节 · N」。点击展开后，选择标题即可定位到原回复的对应位置，也能使用方向键选择标题。随后可用「返回阅读处」回到跳转前的位置。

标题只取自已加载的页面内容，每条回复最多 64 个。流式生成和标题修改会更新目录；旧消息先按现有原生分页机制恢复，再重新寻找真实标题。标题已经变化或消失时，会提示并保留在所在回复，不宣称已定位到不存在的章节。

### 密集节点精确选择

鼠标单击相邻节点不足 8px 的轨道区域时，展开附近 10 条消息供选择，不立即滚动聊天。上下按钮逐组查看，点击「退出附近」恢复原显示范围。

搜索、收藏筛选和消息范围切换会退出附近模式，避免搜索仅覆盖附近几条。时间轴始终固定高度、每条消息保持独立节点。键盘聚焦圆点后按 Enter 仍可直接定位。

### 当前列表导出 Markdown

目录底部「导出」将当前列表保存为 `.md`：

- 无筛选：导出当前显示范围内的已加载消息。
- 搜索中：只导出命中的消息，正文导出整条消息。
- 收藏筛选：只导出当前会话的收藏消息。
- 附近模式：只导出当前这一组附近消息。

已挂载内容尽量保留标题、代码块、列表、表格、引用和常见公式。未挂载消息使用已观察到的纯文本缓存并在文件中注明；缓存截断也会注明。不会后台补全未加载消息，不下载图片或附件原文件。复杂交互卡片和未知内容结构可能有格式损失。

文件只在用户点击导出时生成并下载。不会将正文写入扩展存储，权限仍为 storage，收藏备份格式仍为 v1。

新增覆盖包括：隐藏标题排除、流式标题更新、长回复内段落位置、旧页标题重新挂载、标题消失时回退、密集区域分页不滚动正文、筛选范围导出、原生文件下载、代码内反引号和表格保留、不安全链接处理、未挂载正文回退提示，以及不持久保存正文。

ego-browser 另验证了实际下载：筛选后只导出 1 条回复，保留标题和 shell 代码；600 条消息下的附近选择显示 10 条，聊天 scrollTop 不变；350px 窗口无横向溢出。

## 代码入口

- `src/adapter.js`：提取标题、导出常见 DOM 结构。
- `src/content.js`：章节展开与定位、附近列表、文件下载及范围控制。
- `src/core.js`：节点密度与附近范围计算。
- `src/extras.css`：章节列表和附近选择器，继承现有主题。
- `tests/browser_test.py`、`tests/navigation_browser_test.py`、`tests/reading-tools.test.cjs`：对应功能验证。

本地演示的「体验长回复」可添加包含多个标题和代码块的示例内容。截图 `docs/reading-tools-v1.6.png` 来自实际运行的本地演示。
