## 与这次问题直接相关的 23 项导航测试

空闲观察期间不滚动、不分页、不执行虚拟列表定位，也没有扩展数据请求。进入页面不会为了时间轴补全历史。

已挂载节点直接定位真实消息。以前观察过但已卸载的节点点击后，按原生滚动实际连续翻过七页，再验证目标消息 ID 与可见位置；也测试了从旧位置向新位置跨七页恢复。

Chat/Work 的共同轮次包装下，提问与回复仍分别定位到正确元素，而不是都停在同一轮次顶部。

原生分页延迟 2.3 秒时等待加载，而不是把短暂不变的 DOM 当作历史结束。可变高度虚拟列表和负数 column-reverse 滚动坐标均测试了实际旧节点恢复。

遇到原生“Load earlier messages”按钮时按需加载，不点击侧边栏中的同名按钮。找不到目标时测试有限停止、保留重试提示、不打开缓存阅读窗口。失败分支测试为缩短运行时间，把该测试环境中的上限设为 2.2 秒；生产常量 60 秒 / 320 步 / 8 秒无进展由核心检查验证，不把短测试声称为一分钟实测。

MAIN/ISOLATED 测试通过 Chromium DevTools 创建真正分离的 JavaScript 世界：确认隔离脚本看不到页面的 React expando，主世界助手仍能匹配已观察的稳定 key 并请求定位。前方新增索引偏移后，使用当前 key 而不是旧 ordinal；共同轮次通过 turn key 定位后再校验具体回复。

故意让原生助手错误定位并返回“已执行”，验证不会立即报告成功；实际滚动兜底最终找到准确目标。该测试检查真实 DOM，而不是只检查方法调用次数。

手动滚轮、Esc、取消按钮、第二次点击、会话切换、关闭扩展、销毁均测试了停止后续定位动作。修复了取消期间异步等待结束后重新显示“定位中”的竞态。网页已经开始的加载可以完成，但旧扩展任务不能继续拉回滚动位置。

跨页后仍保留 120 个已观察节点，首尾固定、上方更密，无滑块 DOM；对轨道赋值 scrollTop 也没有内部滚动。诊断与持久存储不包含消息正文、原始消息标识或会话 URL。

## 其他回归

沿用并重跑 57 项通用测试及 24 项索引专项：新旧 DOM、中文搜索、流式消息、收藏与恢复、路由切换、角色范围、400px 设置页、快捷键、三行预览、主题、400 节点浏览器布局、索引暂时空窗与 DOM 重用。

设置断连测试现在等待状态轮询，避免点击已经因断连禁用的“重新识别”按钮。未把这种测试脚本的等待问题掩盖成扩展功能失败。

旧“未挂载时打开缓存”的测试已替换为“启动可取消网页导航且不创建缓存弹窗”；正文缓存仅用于搜索、预览与标识，不作为跳转完成的证据。

静态检查确认清单所有文件存在、版本一致、生成 CSS 与维护源一致，权限仍只有 storage，没有运行时聊天 API 请求、令牌读取、远程可执行脚本、eval、可执行 HTML 注入或第三方网络客户端。

## 截图与离线演示

工程内截图为本地模拟 UI，不是登录账号截图。`demo/navigation.html` 是可直接在浏览器打开的本地分页演示，预置模拟的已加载历史，用于手动检查旧节点恢复。额外冒烟测试以相同顺序载入演示 HTML、CSS 和脚本，确认旧节点恢复经过 7 页、无脚本异常及扩展数据请求；这不计入上面 190 项。该环境禁止 file:// 导航，因此没有直接打开文件路径的实机证明。原版轨道外观保持，但不声明与上游长画布/滑块布局像素一致。

## 未验证的范围

没有在登录后的真实 ChatGPT 账号上运行，没有验收所有灰度 DOM、真实 React 组件、原生扩展安装/通信、Edge 实机、浏览器重启后存储持久化。

MAIN/ISOLATED 的真实执行隔离不等于真实 ChatGPT 网站代码测试；网页标记、私有虚拟列表和加载机制依然可能变化。上述 190 项通过不能推出“所有账号保证自动跳转”。缺少稳定 ID、相同正文重复、同一 URL 切换分支、目标已删除或原生网络失败仍是已知边界。
