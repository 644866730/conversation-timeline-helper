## 结论与范围

此次修复解决本地可复现的两个缺口：预览关闭按钮被时间轴截获；预览关闭后的网页焦点恢复把阅读位置带到旧附件。
提供的用户截图不足以唯一确定实际账号的 DOM 事件链，因此这里不把模拟复现称为真实账号实测。

## 旧版基线与新版比较

同一套本地模拟中，v1.4.1 在 2 项目标测试中均出现预期缺陷；v1.4.2 在相同测试中通过。
其中原生焦点回到旧附件的场景，基线阅读 scrollTop 从 13885 变到 436。
新版校验回到打开预览之前的实际阅读位置，误差不超过 2 CSS 像素。
这两个基线失败是保留的缺陷证据，不是声称新版仍有 2 项失败。

## 27 项预览回归覆盖

1. 关闭按钮与时间轴上方节点重叠时仍点中关闭按钮。
2. 关闭时立即返回旧附件的原生焦点不改变最终阅读位置。
3. Esc 关闭并延迟 480ms 恢复焦点。
4. 点击遮罩关闭。
5. 未漂移时零额外滚动写入。
6. aria-hidden、inert / 显式滚动锁和 overflow:hidden 期间保持索引与检查点。
7. 预览内不响应时间轴快捷键、不后台定位。
8. 预览 DOM 中的消息副本不混入聊天索引。
9. 上方消息高度变化时按消息视口偏移恢复。
10. 滚动容器替换后按稳定消息标识恢复。
11. 切换会话时清除旧位置。
12. 关闭后新手动滚动取消剩余校正。
13. 关闭后新的鼠标操作不被拖回。
14. 嵌套预览全部关闭才恢复。
15. 原生 dialog.showModal 与 Esc。
16. 普通聊天点击不会启用预览恢复。
17. 关闭后主动点击旧节点仍正常导航。
18. 程序打开预览时取消正在进行的跨页定位。
19. 快速关闭并重新打开，避免多个检查点互相争抢位置。
20. 销毁扩展取消全部待执行任务。
21. 关闭扩展开关时丢弃预览检查点。
22. 不持久保存阅读位置，不为预览发送原生 seek。
23. 整页滚动布局。
24. 不相关的隐藏 main 不会暂停真实会话。
25. 关闭清理期间的新时间轴快捷键正常覆盖恢复逻辑。
26. 已知虚拟列表卸载原视口后按原坐标框架恢复。
27. column-reverse 负 scrollTop 坐标恢复。

## 回归未改变的行为

不后台补全完整历史；只索引本页加载过的消息；时间轴固定高度、无内部滑条；顶部最旧、底部最新；旧节点压密。
主动点击以前加载过的节点仍可按需恢复原生分页并校验目标 DOM；不会用缓存正文窗口冒充定位。
