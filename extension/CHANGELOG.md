# Changelog

## 1.3.0 · 2026-10-16

按用户最新要求撤销自动完整历史：删除 history-core、history-client、history-index 和 page-bridge 运行文件；manifest 只保留隔离世界内容脚本。旧自动加载设置不再被读取。

增加纯 DOM loaded-index：保留本次已加载节点，利用重叠锚点处理上翻插入、末尾追加、虚拟卸载与重新挂载；切换会话清空。

时间轴改为固定屏幕高度；顶部最旧、底部最新，按照顺序和密度自适应压缩，旧节点上方更密。删除滑块和内部滚动，保留逐条节点、原版配色和预览。

密集节点增加最近坐标命中和 ↑/↓、Home/End 键盘选择。搜索/收藏筛选仅影响目录，不移动总览首尾。已卸载的消息显示缓存，不自动翻页寻找。

设置页删掉全部历史自动加载入口，显示“随页更新”与已观察/挂载计数；保留 400px 布局并增加手动重建本页索引。

本次测试范围与截图见 docs/TEST_REPORT.md，不沿用旧版“完整历史”或“0 像素差异”测试结论。
