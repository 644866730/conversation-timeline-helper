# 更新记录

## 1.8.1 · 目录入口位置修复

- 将页面侧边的目录入口与时间轴轨道整体下移 64px，为网页顶部的下载、全屏等原生按钮留出操作空间。
- 同步缩短轨道可用高度，底部仍保留 40px，目录入口不会遮住最旧消息节点；左右停靠均生效。
- 设置、收藏格式、站点范围与权限保持兼容。更新扩展并刷新网站后生效。

## 1.8.0 · 界面语言切换

- 新增简体中文、繁体中文、英语、日语、韩语、西班牙语、法语和德语，默认跟随浏览器；不支持的浏览器语言回退英语。
- 弹窗和独立设置页均可选择语言，在本地保存并实时同步到已打开的 ChatGPT、Gemini 时间轴。
- 覆盖设置、目录、按钮、搜索提示、无障碍标签、导航状态与 Markdown 导出说明；聊天正文和章节原文保持不变。
- 切换语言保留搜索、收藏、章节展开、面板及阅读状态；调整长译文换行和窄目录入口布局。
- 翻译字典随安装包离线提供，不新增网络请求或权限，收藏备份仍使用 v1 格式。

## 1.7.0 · Gemini 支持

- 同一扩展适配 `gemini.google.com`：提问/回复时间轴、搜索、收藏、回复章节、密集选择、返回阅读处和 Markdown 导出。
- 按真实 Gemini custom elements、稳定轮次容器与内部 infinite-scroller 识别，支持 light-theme/dark-theme 跟随。
- Gemini 仅运行 DOM 隔离脚本，主动点击后按需滚动恢复；ChatGPT 的 MAIN 定位助手不注入 Gemini。
- 两平台收藏作用域隔离，旧 ChatGPT 收藏与 v1 备份格式保持兼容；首次对话从临时地址升级到稳定地址时保留首条提问。
- 设置文案、隐私说明与站点匹配范围同步更新；显式权限仍只有 storage。

## 1.6.0 · 章节导航、密集选择与 Markdown 导出

- 回复下可展开实际标题，定位到具体章节；流式更新保持消息标识，旧页恢复后重新校验标题。
- 鼠标点击密集节点时打开附近消息选择器，每组 10 条，可前后翻组并退出；不改变时间轴高度或后台滚动。
- 新增按当前列表范围导出的 Markdown 下载，支持搜索、收藏与附近消息；常见代码块、表格、标题保留结构，离线正文缓存回退会明确标记。
- 更新导出隐私说明及演示；权限和收藏格式不变。

## 1.5.0 · Soft Utility 与阅读往返

- 统一深青 / 雾绿 / 薄荷视觉系统，共享离线主题变量；重做目录、设置、预览和说明页面。
- 增加页面目录入口、搜索命中上下文与高亮、搜索结果键盘选择。
- 增加内存中的阅读返回栈，跳转后可恢复消息内相对阅读位置。
- 搜索时复用轨道节点；保留固定高度、无滑条、旧节点压密及原生分页 / 预览保护。
- 修复 Windows 样式生成换行差异，扩展浏览器测试对共享主题和可指定 Chromium 的支持。
- 收藏格式和权限不变；新增锚点只在标签页内存使用。

## 1.4.2 · 图片 / 附件预览阅读位置修复

- 原生预览打开时隐藏并禁用时间轴，避免关闭按钮被上方节点截获。
- 暂停扫描、当前位置更新、快捷键和未完成的定位；预览中的 DOM 副本不作为聊天消息。
- 记录预览打开前的真实阅读锚点和视口内偏移，关闭后仅在位置漂移时进行有时限的校正。
- 支持关闭按钮、Esc、遮罩、嵌套弹窗、滚动锁、重新挂载与虚拟列表；不恢复上一次点击过的旧节点。
- 新的手动输入、会话切换、禁用或卸载会清除待执行的校正。
- 不增加权限，不增加网络请求，不恢复后台补全历史。
- 真实账号仍须由发布者验收；本次复现与回归均为本地 Chromium 模拟。
