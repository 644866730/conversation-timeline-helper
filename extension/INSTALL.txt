对话时间轴助手 v1.8.0 · ChatGPT 与 Gemini

一、首次安装

无需编译、API Key 或后端服务，安装不需要 Node.js 或 Python。
解压运行包，在 Edge 打开 edge://extensions/，或在 Chrome 打开 chrome://extensions/，启用“开发者模式”，点击“加载已解压的扩展程序”。
选择直接包含 manifest.json 的目录，刷新 ChatGPT 或 Gemini 标签页。
支持 chatgpt.com、chat.openai.com 与 gemini.google.com 的顶层页面。
打开一段对话后，点击页面边缘的“目录”查看已加载消息；圆点可定位，搜索框可查找关键词。

二、更新已有版本

1. 先从旧版“高级与数据 → 本地收藏与备份”导出收藏，并备份原安装目录。
2. 在原扩展目录更新文件；如曾填写发布者、支持联系方式或个人元数据，请先备份并保留你的有效配置。
3. 在扩展管理页点击“重新加载”，刷新 ChatGPT 和 Gemini 已打开的标签页。
4. 1.7.0 新增 Gemini 站点访问；如果浏览器显示新增站点访问确认，请按实际浏览器提示处理。
5. 确认设置页版本为 v1.8.0，只启用一个版本。不同扩展 ID 的本地存储不自动迁移，必要时导入收藏备份。

收藏备份格式仍为 v1，既有 ChatGPT 收藏键保持兼容，Gemini 收藏使用独立的平台作用域。
同一扩展内的显示、主题、语言和快捷键设置共用。没有稳定会话 ID 的页面只保留临时收藏。
刷新会重建本页内存索引；扩展不自动从账号读取其他会话或补全全部历史。

三、Gemini 使用说明

在 https://gemini.google.com/app 打开或选择对话。
会话地址识别支持普通 /app/<会话ID>、Gem /gem/<GemID>/<会话ID>、/share/<分享ID>，以及相应 /u/<账号序号>/ 前缀。
仅将页面实际加载、可识别的用户提问和 Gemini 回复加入时间轴。
Gemini 采用 DOM 观察与主动选择后的原页面滚动恢复，不注入 ChatGPT 的 React MAIN 定位助手。
已挂载消息可直接跳转；旧节点能否恢复取决于网站原生加载行为，失败会给出提示。

四、常用操作

- “查看章节”：在有实际标题的回复中选择具体章节。
- 密集圆点区域：单击后按每组 10 条消息精确选择，或用方向键和 Enter 操作圆点。
- “返回阅读处”：回到刚才主动跳转前的阅读位置，只在当前标签页内存保留。
- “导出”：按当前显示、搜索、收藏或附近消息列表生成 Markdown，仅包含已加载内容。
- 图片/附件预览：打开期间暂停时间轴交互，关闭后尝试保持实际阅读位置。
- 定位时按 Esc、使用滚轮或点击“取消”可停止扩展后续导航。

五、界面语言

在“常用设置 → 界面语言”选择简体中文、繁体中文、英语、日语、韩语、西班牙语、法语、德语或跟随浏览器。
切换后本地自动保存并实时更新已打开的时间轴，聊天正文和章节原文不翻译。

六、发布与验证边界

运行包的 manifest.json 在 ZIP 根目录；完整源码包还包含测试与文档，不应替代商店上传包。
公开上架前，应同步更新商店中的支持站点、隐私披露与 Gemini 站点访问说明。
唯一显式 API 权限仍为 storage；不读取密码或登录令牌，不自行请求会话接口，不上传聊天。
本版本已查看已登录 Gemini 的页面结构，但这不代表所有真实账号、灰度布局和完整功能均已实测。
先用无私人内容的测试对话检查消息识别、首尾跳转、搜索、收藏、章节、导出和图片预览。
具体适配机制与限制见 docs/COMPATIBILITY.md；实际验收范围以当前版本的测试记录为准。
