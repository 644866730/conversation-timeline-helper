对话时间轴助手 v1.4.2 · 图片 / 附件预览位置修复

一、先在本地验收，不要直接把未经你账号验证的代码公开上架

本修复包不需要编译、API Key、服务器或运行依赖。
首次安装：解压完整工程，在 chrome://extensions/ 开启开发者模式，
点“加载已解压的扩展程序”，选择直接包含 manifest.json 的目录，刷新 ChatGPT 标签页。

已有本地开发版：
1. 从旧扩展设置中导出收藏备份。备份原安装目录，尤其是 manifest.json。
2. 将新版 manifest.json、src/、popup/、icons/ 覆盖到原安装目录，保持目录路径。
   不要覆盖你已经填写发布者/邮箱的隐私政策和网站文件。
3. 若旧 manifest.json 有 key 字段，把原 key 原样保留到新版 manifest.json。
   这是本地固定扩展 ID 的公钥，不是登录密钥；不要随意替换。
   自己增加过的 homepage_url 等元数据也应保留。只有本地副本这样处理。
   提供的商店上传 ZIP 不含开发用 key。
4. 在扩展管理页点击“重新加载”，然后刷新全部 ChatGPT 标签页。
5. 确认弹窗版本为 v1.4.2，只启用一个版本。不同扩展 ID 的存储不会自动迁移，必要时导入备份。

注意：更新后必须刷新网页，否则旧内容脚本和 MAIN 定位助手仍可能运行。
本页“已加载消息”内存索引会随刷新重建，这是原有行为。

二、验收本次修复

打开一段无私人内容的测试对话，手动滚到含图片/附件的中后段，记住当前可见文字。
打开图片 → 关闭，检查停留在刚才的同一段文字，不跳回上一次时间轴节点。
分别检查：右上角关闭按钮、Esc、点击背景、连续打开两张图。
再点击一个以前手动加载过的旧节点，确认按需自动翻页定位仍正常。
预览打开期间时间轴会暂时隐藏、暂停扫描；关闭动画及焦点恢复结束后恢复。
关闭后位置没有漂移时，扩展不会额外滚动页面。
用户再次滚动、点击或使用时间轴快捷键会终止短暂的位置校正。

三、更新已有 Chrome 商店条目

进入现有扩展条目 → 文件包 → 上传新软件包，上传：
Conversation-Timeline-Helper-v1.4.2-store-upload.zip
不要新建另一个条目，不要把完整源码包当作商店上传包。
代码更新后须重新提交审核；若旧草稿已在审核，按后台状态先取消该次审核再更新。
首次发布的邮箱验证和公开隐私政策网址仍需要你自己完成；本包不会替你提交审核或部署网站。

版本已递增为 1.4.2。权限仍为 storage，内容脚本仍只匹配两个 ChatGPT 域。
本次只在标签页内存临时保留预览前的消息锚点和视口偏移，不新增持久存储或网络请求。

四、验证边界

本次在本地 Chromium 模拟了关闭按钮与节点重叠、原生焦点恢复到旧附件、滚动锁等触发路径。
未在你的已登录 ChatGPT 账号实测。实际网页的灰度 DOM、关闭动画和虚拟化机制仍需真实环境验收。
不会为了关闭图片而后台补全全部聊天，也不会在未知的新页面上按旧节点序号盲目导航。
