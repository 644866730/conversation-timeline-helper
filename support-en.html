Use and support

Start with these troubleshooting steps. The extension processes loaded content in the current conversation.

Contact the publisher

Publisher: GuanChanghao

Support and privacy contact: NikieRamamonjisoa@gmail.com

Include the extension version, browser version, whether you use ChatGPT or Gemini, and steps to reproduce the issue. Do not send passwords, verification codes, cookies, login tokens, or private conversations.

Install the source in Edge or Chrome

Open edge://extensions/ in Edge or chrome://extensions/ in Chrome, enable developer mode, and load the repository's extension folder, which directly contains manifest.json. Do not load the repository root. Export bookmarks before updating and keep only one version enabled.

The timeline does not appear after installation

  1. Check that the extension is enabled and allowed to run on the relevant website.
  2. Open a conversation on chatgpt.com, chat.openai.com, or gemini.google.com.
  3. Refresh the page after installing or updating the extension.
  4. Open the extension popup to check its connection, then try Rescan.

An older message is missing or cannot be located

The extension does not automatically load all history in the background. Use the website to load the content you need; the extension records messages actually observed on this page. Selecting an older observed marker may attempt to restore its original message. Website structure or virtual lists may prevent recovery, in which case a retry notice is shown. Manual scrolling, Esc, or Cancel stops subsequent navigation actions.

Search, bookmarks, and sections

Open the page's outline and enter a search term, or use a star button to bookmark a message. Replies with actual headings offer a sections list. Back to reading returns to the position before a navigation jump. Changing the interface language does not translate conversation text or section headings.

Change language and appearance

Use General in the popup or standalone settings page to choose interface language, light/dark appearance, and left/right placement. Simplified Chinese, Traditional Chinese, English, Japanese, Korean, Spanish, French, and German are available, along with an automatic browser-language option. Language switching preserves search, bookmarks, and reading state.

Export or delete local data

Export in the outline downloads Markdown for the loaded messages in the current filter scope. Advanced & Data provides bookmark backup, Clear bookmarks, and Restore defaults. You control saved export files and must delete them separately. Clearing extension data does not delete the original website conversations.

Share diagnostics

You can explicitly export diagnostics from Advanced & Data and review the file before sending it. Diagnostics are designed to exclude conversation bodies, raw message IDs, conversation URLs, search terms, and custom selectors. Nothing is uploaded automatically. Screenshots may expose chat content; redact it or reproduce the issue in a nonprivate test conversation.
